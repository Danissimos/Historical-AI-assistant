# Historicval AI-assistant

ИИ-ассистент на основе больших языковых моделей (LLM) и технологии Retrieval-Augmented Generation (RAG), предназначенный для формирования контекстно-зависимых ответов на основе базы знаний.

## Основные возможности

- **Гибридный поиск** — объединение BM25 и векторного поиска для повышения релевантности найденных документов.
- **RAG-пайплайн** — извлечение релевантного контекста из базы знаний и генерация ответов на его основе.
- **Интеграция с PostgreSQL** — хранение векторных представлений и выполнение поиска по сходству с использованием pgvector.
- **Графовая база знаний** — использование Apache AGE для представления и обработки графовых связей между сущностями.
- **Мониторинг LLM** — трассировка и анализ взаимодействий с языковой моделью с помощью Langfuse.
- **Пользовательский интерфейс** — удобное взаимодействие с ИИ-ассистентом через графический интерфейс.

## Технологический стек

Python · LangChain · PostgreSQL · pgvector · Apache AGE · Langfuse · Sentence Transformers

## Версия

**v1.0.0** — первый релиз проекта, включающий базовый RAG-пайплайн, гибридный поиск, интеграцию с базами данных, мониторинг взаимодействий с LLM и пользовательский интерфейс.
